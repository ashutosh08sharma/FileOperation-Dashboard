# File Operation Dashboard

## Getting Started

### Prerequisites
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run start
```

The app will be available at `http://localhost:5173`

### Build

```bash
npm run build
```

### Preview Build

```bash
npm run preview
```

## Technology Stack
- **React** 18.2
- **TypeScript** 5.2
- **Vite** 5.0
